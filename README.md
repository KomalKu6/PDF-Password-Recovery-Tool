# PDF Password Recovery Tool 🔐

A Python-based project designed to demonstrate PDF password verification and recovery concepts using the `pikepdf` library.

## 🚀 Features

- **PDF Password Verification:** Checks whether a supplied password can open a protected PDF.
- **Wordlist Support:** Reads password candidates from a text file.
- **Password Generation:** Demonstrates generating password combinations.
- **Multithreading:** Uses Python's `ThreadPoolExecutor` for concurrent processing.
- **Progress Tracking:** Uses `tqdm` to display progress.
- **Command-Line Interface:** Uses `argparse` to accept user inputs and options.

- pikepdf
- tqdm
- itertools
